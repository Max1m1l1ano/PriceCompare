# PriceCompare - Quebec City Grocery Price Comparison Platform

## 📋 Project Overview

**PriceCompare** is an intelligent grocery price comparison platform specifically designed for Quebec City residents. The application helps users find the lowest prices for grocery items across all major Quebec grocery chains while providing optimal shopping routes and personalized recommendations.

## 🎯 Project Goals

1. **Complete Quebec Market Coverage**: All major grocery chains (IGA, Metro, Provigo, Super C, Maxi, Walmart, Costco)
2. **Real-Time Pricing**: Live price data vs outdated weekly flyers
3. **Quebec-First Design**: French-first interface with authentic Quebec cultural integration
4. **AI-Powered Optimization**: Smart shopping routes, price predictions, and personalized recommendations
5. **Legal Compliance**: Full adherence to Quebec privacy laws and consumer protection regulations

## 🏗️ System Architecture

### Technology Stack

**Backend:**
- **Node.js/TypeScript** (primary API services)
- **Python** (ML/AI processing, data collection)
- **PostgreSQL + PostGIS** (geographic data storage)
- **Redis** (caching and session management)
- **Google Cloud Platform** (Montreal data center for Quebec residency)

**Frontend:**
- **React with Next.js** (web application)
- **React Native** (mobile applications)
- **French-first design** with English secondary support

**AI/ML Stack:**
- **Sentence Transformers** (product matching)
- **Prophet + LSTM** (price prediction)
- **TensorFlow Lite** (mobile edge computing)
- **Differential Privacy** (privacy-preserving ML)

### Architecture Highlights

- **Microservices Design**: Independent scaling and fault isolation
- **Quebec-Specific Features**: Bilingual support, local transportation integration
- **Scalability**: Handle 25% market penetration (71,250 households)
- **Performance**: Sub-second response times with intelligent caching
- **Security**: Defense-in-depth with Quebec data residency compliance
